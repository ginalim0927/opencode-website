# Research for Defense Against AI Agent Attacks

One-page website describing our research project on AI cybersecurity and
defense against rogue AI agents.

## Prerequisites

Python 3
A modern web browser (Chrome, Safari, or Firefox)

## Local run

No build step or dependencies are required.

Serve the project locally (only on localhost):

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

## Stop Server

Return to the terminal running the server and press Control + C.
